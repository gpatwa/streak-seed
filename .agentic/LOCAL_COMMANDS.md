# Local Commands — StreakKeeper

Dependency-free Node ESM (Node 18+). No install step (no dependencies).

- `npm run typecheck` — `node --check` every source file.
- `npm test` — `node --test` (the test suite).
- `npm run build` — import-check: every module loads cleanly.
- `npm run qa:mvp` — typecheck + test (the QA gate).
- `npm start` — run the service locally.

(Exact scripts are finalized by the Architect/engineer at delivery; this is the
intended shape, matching the stash-seed reference.)
